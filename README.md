# Immersive Seat Preview

Simulador de Assento 3D / Preview Sensorial da Sala

Ao comprar ingressos, o site oferece uma visualização em 3D/VR de como a tela será vista exatamente daquela fileira específica (incluindo a simulação do efeito 270° do ScreenX ou a amplitude do IMAX).  faça um codigo completo, comentado, funcional e otimizado, quero uma estetica vermelha e preta, e faça tudo completo, com as imagens de uma sala (pode ser feita artificialmente) e quero que seja usado a linguagem de python, css e html
